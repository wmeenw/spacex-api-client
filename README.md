# SpaceX Launch Explorer

Консольное приложение, которое показывает запуски SpaceX. Данные берутся из публичного API [api.spacexdata.com](https://api.spacexdata.com). Ответы кешируются в файлы, поэтому при недоступности сервера приложение работает с сохранёнными данными.

Домашнее задание 4 по Java.

## Возможности

- Список всех запусков.
- Последний запуск.
- Поиск запусков по дате.
- Фильтр только успешных и только неудачных запусков.
- Очистка кеша из меню.
- Работа без сети: если сервер недоступен, показываются данные из кеша.
- Собственный разбор и формирование JSON без внешних библиотек.

## Меню

```
=== SpaceX Launch Explorer ===
1. Показать все запуски
2. Показать последний запуск
3. Поиск запусков по дате
4. Показать только успешные запуски
5. Показать только неудачные запуски
6. Очистить кеш
7. Выход
```

## Архитектура

| Класс | Ответственность |
|-------|-----------------|
| `SpaceXMenu` | Меню и ввод пользователя |
| `Core`, `Failure` | Вспомогательные классы проекта |
| `SpaceXHttpClient` | HTTP-запросы к API (`HttpURLConnection`) |
| `JsonParser` | Разбор JSON-ответов |
| `JsonBuilder` | Формирование JSON |
| `CacheManager` | Файловый кеш в папке `cache/` с метаданными в `cache_meta.json` |
| `Launch` | Модель запуска |
| `Main` | Точка входа: собирает зависимости и запускает меню |

Базовый адрес API задан в `SpaceXMenu`: `https://api.spacexdata.com`.

## Требования

- JDK 25 (в `pom.xml` указан `maven.compiler.source` 25).
- Maven 3.9+.

## Сборка и тесты

```bash
cd hmework4
mvn clean test
```

Тесты покрывают кеш, JSON-парсер, построитель JSON и HTTP-клиент.

## Запуск

```bash
cd hmework4
mvn clean package
java -cp target/classes org.example.Main
```

Кеш создаётся в папке `cache/` в каталоге запуска.
